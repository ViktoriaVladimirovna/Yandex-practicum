# Описание

Проведен маркетинговый анализ развлекательного приложения Procrastinate Pro+ с целью выявления причин убытков при высоких рекламных затратах. Составлены профили пользователей, определены наиболее прибыльные страны и устройства. Рассчитаны CAC, LTV и ROI по рекламным каналам, выявлены неэффективные источники и сегменты. Проанализирована динамика конверсии и удержания пользователей. Сформированы рекомендации по оптимизации маркетинговой стратегии и перераспределению рекламного бюджета.
