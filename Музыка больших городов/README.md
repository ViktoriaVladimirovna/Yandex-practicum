# Описание

Отработка базовых навыков Python. Проведен анализ данных Яндекс.Музыки для сравнения музыкальных предпочтений и активности пользователей в Москве и Санкт-Петербурге. Выполнена предобработка данных, включая обработку пропусков и дубликатов. Проверены гипотезы о зависимости активности от дня недели, различиях в жанровых предпочтениях в зависимости от времени суток и различиях в популярных жанрах между Москвой и Санкт-Петербургом. Сформулированы выводы.
