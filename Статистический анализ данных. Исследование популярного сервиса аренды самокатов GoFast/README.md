# Описание

Проведен анализ данных сервиса аренды самокатов GoFast для проверки гипотез, направленных на увеличение количества пользователей с подпиской. Выполнен исследовательский анализ данных о пользователях и поездках, выделены характеристики пользователей с подпиской и без. Рассчитана помесячная выручка по группам пользователей. Проверены статистические гипотезы о времени поездок, расстоянии и помесячной выручке. Рассчитано необходимое количество промокодов для акции по продлению подписок и оценена вероятность открытия push-уведомлений. Результаты анализа использованы для разработки рекомендаций по акциям и маркетинговым стратегиям.
