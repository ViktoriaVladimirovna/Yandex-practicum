# Описание

Проведен анализ данных интернет-магазина компьютерных игр «Стримчик» с целью выявления закономерностей успешных игр и прогнозирования продаж. Выполнена предобработка данных, включая обработку пропусков и преобразование типов данных. Проведен исследовательский анализ динамики продаж по платформам и жанрам, выявлены наиболее прибыльные платформы и жанры. Составлен портрет пользователей по регионам с учетом предпочтений по платформам, жанрам и влиянию рейтинга ESRB на продажи. Проверены статистические гипотезы о пользовательских рейтингах платформ и жанров. Результаты анализа использованы для формирования рекомендаций по определению потенциально успешных продуктов.
