# Описание

Проведен анализ A/B-теста и приоритизация гипотез для увеличения выручки интернет-магазина. С использованием фреймворков ICE и RICE приоритизированы 9 гипотез, определено влияние фактора “Reach” на изменение приоритетов. Проанализированы кумулятивные метрики (выручка, средний чек, количество заказов на посетителя) для групп A и B, выявлены аномальные значения (заказы и пользователи). С использованием статистических тестов (Mann-Whitney U-test) оценена статистическая значимость различий между группами по сырым и очищенным данным.
