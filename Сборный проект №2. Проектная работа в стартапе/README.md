# Описание

В целях повышения качества взаимодействия пользователей с приложением было изучено поведение пользователей с помощью логов событий мобильного приложения, построена воронка событий, выявлены узкие места и исследуемы результаты A/A/B-эксперимента. Сформированы рекомендации по оптимизации пользовательского пути, фокусируясь на улучшении проблемных этапов воронки.
