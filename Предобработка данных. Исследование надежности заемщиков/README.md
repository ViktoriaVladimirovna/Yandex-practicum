# Описание

Проведено исследование платёжеспособности заёмщиков для построения модели кредитного скоринга. Выполнена предобработка данных, включая обработку пропусков, замену типов данных и устранение дубликатов. Проанализировано влияние семейного положения, количества детей, уровня дохода и цели кредита на своевременность погашения кредита. Выявлены статистические зависимости и сформулированы рекомендации для кредитного отдела.
