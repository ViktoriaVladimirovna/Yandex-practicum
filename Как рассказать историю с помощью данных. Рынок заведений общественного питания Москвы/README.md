# Описание

Проведен комплексный анализ рынка общественного питания Москвы с целью определения оптимальных локаций и форматов для открытия новой бизнес-точки.
- выполнена предобработка данных и анализ распределения заведений по категориям, районам и сетевой принадлежности;
- выявлены топовые сети, популярные улицы с высокой концентрацией заведений, а также районы с наибольшей концентрацией заведений определенной категории;
- с использованием геоаналитики и библитеки folium визуализированы средние рейтинги и ценовые индикаторы по районам;
- проанализированы часы работы заведений и их зависимость от расположения и категории;
- отдельное внимание уделено анализу рынка кофеен, их распределению, рейтингам и ценообразованию для формирования рекомендаций по открытию успешной кофейни в Москве;
Результатом проекта стали конкретные рекомендации для выбора оптимальной локации и формата новой кофейни, основанные на данных об уровне конкуренции, ценах, клиентском трафике и рейтингах заведений.
