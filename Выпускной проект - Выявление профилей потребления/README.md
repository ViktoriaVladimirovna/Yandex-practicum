# Выпускной проект - Выявление профилей потребления

Цель: проанализировать данные интернет-магазина и дать рекомендации по увеличению продаж и лояльности клиентов, путем сегментированного маркетинга

# Описание проекта:

Шаг 1. Изучение общей информации

Шаг 2. Предобработка данных
- проверить пропуски, явные и неявные дубликаты;
- проверка датафрейма на соблюдение стиля;
- проверить корректность типа данных;
- определить за какой период времени предоставлена информация;
- добавление нужных столбцов;
- определить сколько уникальных пользователей и заказов в датафрейме;

Шаг 3. Исследовательский анализ данных
- обработка аномалий;
- расчет по пользователям: частота покупок, давность покупок и сумма покупок;
- рассчитать и визуализировать динамику выручки по месяцам, учитывая год;
- рассчитать и визуализировать средний чек и его динамику по месяцам, учитывая год;
- рассчитать и визуализировать помесячную динамику средней выручки с покупателя;

Шаг 4. Сегментация покупателей на основании истории их покупок
- сегментировать покупателей на постоянных, неактивных и ушедших клиентов;
- разбить продукты на категории;
- анализ категорий товаров по постоянным, неактивным и ушедшим клиентам (топ-5 продуктов и топ-5 продуктов по категориям);
- определить кол-во покупателей и средний чек по постоянным, неактивным и ушедшим клиентам;
- посмотреть активность постоянных, редких и разовых покупателей во времени;
- сезонность товаров по категориям в разрезе сегментов;

Шаг 5. Проверка статистических гипотез
- средние чеки постоянных, неактивных и ушедших покупателей равны: - ушедшие-неактивные - ушедшие-постоянные - неактивные-постоянные;
- частота заказов постоянных, неактивных и ушедших покупателей равны: - ушедшие-неактивные - ушедшие-постоянные - неактивные-постоянные;

Шаг 6. Написать общий вывод

Шаг 7. Презентация

# Итог: 

В целях увеличения продаж и лояльности клиентов интернет-магазина была проведена сегментация покупателей и категоризация их товаров, а также тщательный анализ сегментированного маркетинга, на основании чего разработана стратегия и общие рекомендации по каждому сегменту покупателей. Использовались Python и RFM-анализ для сегментации клиентов. Проверка статистических гипотез с использованием t-критерия Стьюдента. Сформированы рекомендации по персонализированным маркетинговым кампаниям для каждого сегмента клиентов, основанные на выявленных предпочтениях в категориях товаров и анализе покупательской активности.
