# Описание

Проведен анализ объявлений о продаже квартир для выявления факторов, влияющих на рыночную стоимость недвижимости и автоматизации выявления мошеннической деятельности. Выполнена предобработка данных, включая обработку пропусков, преобразование типов данных и устранение дубликатов. Проведен исследовательский анализ параметров объектов (площадь, цена, количество комнат, высота потолков и т.д.), а также скорости продаж. Выявлены факторы, наиболее влияющие на стоимость, проанализирована зависимость цены от различных параметров (площадь, этаж, дата размещения). Определена средняя стоимость квадратного метра в 10 крупнейших населенных пунктах и проанализирована зависимость стоимости от расстояния до центра Санкт-Петербурга. Результаты исследования можно использовать для настройки автоматизированной системы выявления мошеннических публикаций.
